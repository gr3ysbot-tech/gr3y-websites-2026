Support starts
with trust.

Will it change my computer?+

The current collector reads diagnostic information and saves a local bundle. It does not install a persistent service, update drivers or BIOS, apply repairs, or reboot the computer.

How is diagnostic evidence handled?+

Local collection sends nothing. An explicit upload shares the bundle with the configured support service through a scoped session. Hardware identifiers and event messages can include names or paths; review the destination with your technician.

Can I run it without the full RMM?+

That is the purpose of the standalone tooling. The collector can run without enrolling a computer in the RMM. The signed URL installer is still being prepared; get approved launch instructions from your technician.

Does it already learn and fix issues automatically?+

Today it collects evidence, applies fixed investigation rules, and records reported outcomes. Vendor research, verified outcome ranking, automated verification, and repair execution are future development work.
